## Justification for added tests

Focused contract tests cover exact catalog identity and family coverage, one-pass schema transforms, required caller data, structured paths, discriminated formats, continuous-profile rejection, exact image descriptor sets, custom-theme geometry and font qualification, serialized manifest identity authenticity, frozen descriptor defaults, cross-runtime deterministic ordering, normalized fingerprint completeness, and legacy protocol/theme compatibility. S03 tests additionally cover the static adapter lookup, map key/descriptor identity, omitted-theme behavior, differential colors, preserved component export, and all three plan discriminants. The S04 fixture imports the public root, compiles flattened template props and legacy `style`, and exercises protocol V1, historical metadata, the legacy theme overload, advanced plan types, and Node renderer exports. It does not exercise the future render facade.

## Deviations and resumption

The implementation keeps binary preflight and the render facade in L18. Post-commit reviews identified provenance-based manifest validation, locale-sensitive ordering, a mutable descriptor default, insufficient structural parsing, an input object that did not reject unknown keys, and an inherited-property lookup risk in the partial static resolver. Corrective commits replace those behaviors with value-based digest validation, code-unit ordering, cloned/frozen defaults, strict parsing, and an own-property-only static lookup. L17 is merged into `dev`; this record does not claim a deployment, publication, release, catalog-wide migration, or removal of a released API. L18 remains the next planned lot.
