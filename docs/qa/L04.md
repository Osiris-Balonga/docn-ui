## Justification for added tests

S01 adds one unit file because the unit scope previously had no document-core suite. Its four cases cover distinct pre-render risks together: applying orientation once, rejecting template/format incompatibility with field paths, enforcing custom versus preset dimensions, and preserving invalid data while reporting limits. It does not duplicate L02's real-PDF geometry assertions. Theme/asset and layout coverage will extend this lowest-level suite where natural; the existing feasibility PDF file will be extended only for behavior that requires the engine.

## Visual and document checks
