## Deviations and resumption

- Typed local content replaces the proposed MDX content format for S01. Both retain a trusted, versioned source boundary; this avoids adding a parser dependency for eight structured guides. Architecture and lot acceptance text record the choice.
- Initial lint found an unused import after extracting the copy control; removed before the successful quality run. An initial navigation selector matched both sidebar and content links; scoped it to the guide index region. The 375 px check then exposed real paragraph overflow from a long function name; added article-level wrapping and reran successfully. No threshold was weakened and no failing commit was created.
- No new dependency, license change, publication, deployment, template redesign or automatic theme-inheritance promise.
- Next story: **L12-S02a**, separating shared theme access from fixed-page geometry. Keep the lot in progress until all ten planned stories and their evidence are complete; this documentation milestone is not the completed component catalog.
