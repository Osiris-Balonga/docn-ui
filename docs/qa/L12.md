## S02a — shared themes and fixed/flow frames

Implementation, tests and evidence commit: `06697e17ae68751df08bd4d880b82c7389399711`. Checks below were executed on the story working tree before its commit; no remote CI or completed-lot claim is made.

Implemented after the maintainer accepted S01. `PdfThemeProvider`/`usePdfTheme` no longer require fixed geometry. Existing primitives are split into theme, typography, layout, image, QR and fixed-frame modules, with an unchanged compatibility facade. Pure print geometry is extracted without changing its calculations. No existing template source or design is modified.

`DocumentFrame` adds normal-flow portrait A4/Letter pages with explicitly reserved repeated header/footer regions, independent flow geometry access and measured non-breaking-block validation. The exact API was documented in COMPONENT_CATALOG before its dependents were implemented. It supports trim-sized screen geometry initially; arbitrary JSX height, bleed profiles and automatic oversized-content splitting are not implied. S02c will build reusable pagination components on these bounds.
