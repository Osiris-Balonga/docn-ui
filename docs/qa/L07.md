## Justification for added tests

S01 added one three-case unit file because graph closure and source rewriting are pure security/distribution boundaries that the existing PDF and UI suites cannot cover. It reuses the `unit` project and groups malformed manifests instead of creating one test per validation message. Remaining planned coverage is limited to shared asset security boundaries, one source/copy composition, and two distinct isolated consumers. Static verification covers every item; the expensive real CLI path will install one business-card dependency graph rather than all three cards.
