## Justification for added tests

One existing component-test scope will cover the composed navigation risks: skip navigation, the mobile Sheet, keyboard search, focus restoration, and input shortcut isolation. shadcn primitives will not receive duplicate unit tests, and no PDF scope will be rerun unless the shell changes its isolated qualification route.

## Visual and document checks

Captured `home-375x812-light.png`, `docs-375x812-sheet-light.png`, `docs-768x1024-dark.png`, `docs-1280x800-light.png`, and `home-1440x900-dark-search.png` under the ignored `.artifacts/l03/` directory. The 375 px Sheet focused its current-page link, the 1440 px search focused its input, both themes remained readable, long code scrolled inside its own block, and every inspected viewport reported no global overflow.

The browser surface did not expose a reduced-motion emulator or browser-zoom control. A 720×450 viewport verified the same reflow constraints as 200% zoom on 1440×900, and the production CSSOM confirmed the reduced-motion override while the host preference remained inactive. This limitation is recorded instead of claiming an emulated preference. This lot does not change PDF fixtures or document rendering.

## Deviations and resumption

Browser verification exposed a production Base UI error when the theme menu opened: `DropdownMenuLabel` was outside a Menu group. Commit `a0e81b7` wraps the label in `DropdownMenuGroup`; the rebuilt menu then exposed its Light, Dark, and System radio items normally. No axe dependency was added because semantic browser snapshots and the focused composition tests covered the identified risks without another test scope.

L03-S01 through L03-S03 are implemented and locally verified. The standalone unit scope has no files and therefore returns the configured no-tests error; the CI-equivalent non-PDF aggregate passes all six applicable tests. PDF tests were not rerun because this lot changes only the isolated site shell and imports no PDF engine into documentation routes.
