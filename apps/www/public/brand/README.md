# docn-ui brand assets

These five SVG files are original project artwork owned by Emmanuel Osiris
Balonga and created for docn-ui. They are distributed under the repository's
[MIT License](../../../../LICENSE). This provenance statement applies only to
the files listed below; it does not assert ownership of third-party names,
trademarks, fonts, or artwork.

The light assets are intended for light backgrounds and the dark assets for
dark backgrounds. Next.js publishes `apps/www/src/app/icon.svg` as
`/icon.svg`; its embedded media query selects the appropriate sheet color.

rather than outlined glyphs. Their exact wordmark metrics can therefore vary
when viewed outside the docn-ui site; the vector mark and colors remain fixed.
